## Knowledge Base Introspection

Use `python -m uv run pulser kb` to inspect the knowledge base:

```bash
# Full overview of collected data
python -m uv run pulser kb overview

# List all topics
python -m uv run pulser kb topics

# List all sources
python -m uv run pulser kb sources

# List all collected queries
python -m uv run pulser kb queries

# Search enriched documents
python -m uv run pulser kb search "quantum computing"
```
